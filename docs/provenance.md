# Provenance and publication scope

The result tables are extracted from the completed external-CAD integration experiment and its controls recorded on 2026-11-14. Values are preserved at the precision recorded in the source summaries. Live model mutations, record replay and synthetic ID permutation are labeled separately.

The source records and raw numerical inputs are retained by the authors. This release publishes aggregate verification tables only. `results/manifest.json` lists their checksums. If an anonymous export changes file bytes, regenerate the corresponding checksums after replacement and run the table checker again.

Design code and model-adapter code are supplied so readers can inspect the implementation and run it with their own compatible inputs. Simulation models, exported geometry, field samples, mesh exports, measurement images and measurement tables are not part of this distribution.

GitHub ownership is public. An anonymous mirror needs a separate export with its account links and metadata checked. Previously generated mirrors are independent snapshots and must be refreshed when the publication scope changes.
